# Furry Buddy Grooming Salon Website

This project is my Web Development POE. It includes a fully functional multi-page website with interactive features, SEO optimisation, dynamic content and form validation. All pages are linked and styled using external CSS files, and JavaScript enhances interactivity such as lightbox galleries, enquiry validation, and dynamic footer content.

The project structure includes organised folders for CSS, JavaScript, images, and documents. All files use relative paths so the website works when extracted or hosted. A changelog is included to show development progression.

To view the project, download the repository and open “Home page.html” in any browser.
